## UOW-2202 Summary

This UOW added a guarded system-property path for intentional Java mutation-post artifact capture.

New property:

```text
aion.findGroupMutationPost.artifactRoot
```

Behavior:

- capture flag disabled: no rows and no artifacts,
- capture flag enabled but artifact-root property absent/blank: no files are written and rows remain buffered,
- capture flag enabled plus artifact-root property supplied: drained rows write action `2`/`6` artifacts only beneath the supplied root,
- validator can mark the supplied-root files shape-valid, but runtime comparison readiness remains false.

No repository artifact files are generated by the default focused Maven command.
