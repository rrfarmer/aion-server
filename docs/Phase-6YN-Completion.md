# Phase 6YN Completion - UOW-1152 Trade-List Packet Serializer Evidence

Date: May 26, 2026

## Unit of Work Summary

Continued Phase 6 trade-list parity by adding a concrete, non-live `SM_TRADELIST` serializer from the existing staged packet plan and by pinning the Java no-sell system-message helper. The production `BUY` socket boundary remains non-sending.

The Java implementation is the source of truth:
- `ServerPacketsOpcodes.addPacketOpcode(253, SM_TRADELIST.class)` assigns the trade-list opcode.
- `SM_TRADELIST.writeImpl` writes target object id, trade NPC type index, buy modifier, fixed Aion 4.5 modifier `100`, buy/sell flags, trade tab ids, and limited item rows.
- `SM_SYSTEM_MESSAGE.STR_BUY_SELL_HE_DOES_NOT_SELL_ITEM(String)` returns message id `1300336` with one string parameter.
