## UOW-2201 Summary

This UOW added `FindGroupMutationPostTraceCaptureInMemoryArtifactBridge`, a Java test-side bridge that drains production in-memory hook rows and writes shape-valid fixture artifacts only to an explicit caller-provided root.

The bridge:

- maps production `FindGroupMutationPostTraceCaptureHooks.TraceRow` values to the existing schema-v1 serializer row,
- groups rows by action,
- calls the existing fixture writer for action `2` and `6`,
- writes only to the supplied artifact root,
- returns written paths,
- leaves runtime comparison readiness false through the existing artifact validator.

No repository artifact files are generated by the default focused Maven command.
