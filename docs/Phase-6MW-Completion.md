## Status

Phase 6 is still in progress. This unit reconciled the animation-add item-use cancel end-state found in UOW-848.

Java `AnimationAddAction` does not define an action-specific cancel packet. It relies on generic `PlayerController.cancelUseItem`, which broadcasts a zero-time `SM_ITEM_USAGE_ANIMATION` with `end=3`. C# previously overrode animation-add pending cancellation to `end=2`; this unit removed that override and updated the runtime regression to expect `end=3`.
